# Changelog

## 1.0b — Initial public beta

- Introduced Raffle Game with the REY layout, PeepoBlankie mascot, and compact ticket-selling controls.
- Added numbered ticket sales, gifting, purchase history, CSV export, customizable messages and winner draws.
- Added validation for target-specific ticket tells, persistent raffle state, and previously issued ticket ranges.
- Prepared the plugin for distribution through its own GitHub release and the central ReyPlugins repository.
